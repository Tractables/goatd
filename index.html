Methods and definitions

Valid
A decomposition accepted by the common validator. Coverage is valid results divided by selected graphs.
Best observed
The minimum metric among valid results for one graph. Ties count for every tied solver.
Median excess
The median difference from the best observed value, evaluated where that solver returned a valid result.
Deadline
The runner stops search at the stated budget. Solvers with an internal deadline receive an earlier warning so they can finish and write a decomposition before that cutoff.
Width profile
The denominator is every selected graph; missing and invalid results therefore reduce the percentage.
Component graph
One connected graph passed independently to every solver. This is the default aggregate unit.
Source graph view
The combined result for all components derived from one source. One missing component makes the combined result incomplete.
Tree component
A connected component with |E| = |V| − 1, hence exact width one. These components are omitted by default.
Width
The largest bag size minus one.
Total bag size
The sum of bag sizes, counting a vertex once for each bag containing it.
Bag count
The number of bags in the decomposition.
Elapsed
Search time before normal exit or the fixed budget signal.

Aggregate excess statistics exclude missing results and should be read together with coverage. Instance-level highlighting compares only validated results for the same graph.

Result schema and metric fields are documented in view/README.md.
